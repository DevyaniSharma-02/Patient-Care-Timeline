# Patient Care Timeline

A Salesforce-based healthcare workflow application designed to track a patient's journey from pre-admission through follow-up.

## Features

* Patient journey tracking
* Configurable care stages
* Care task management
* Doctor assignment
* Journey status monitoring
* Salesforce Lightning Web Components (LWC)
* Apex-based business logic

## Technology Stack

* Salesforce Platform
* Apex
* Lightning Web Components (LWC)
* SOQL
* Salesforce DX
* Git and GitHub

## Architecture

Lightning Web Components → Apex Controller → Service Layer → Salesforce Database

## Project Scope

This project demonstrates a Salesforce-native workflow for coordinating patient care stages and tasks. It is a learning project and does not replace a hospital's clinical record system.

## Setup

1. Clone this repository.
2. Open the project in Visual Studio Code.
3. Install Salesforce CLI and the Salesforce Extension Pack.
4. Authorize a Salesforce org.
5. Deploy the metadata to your authorized org.
